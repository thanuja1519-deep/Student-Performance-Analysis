# Student Performance Analysis

## 1. Project Overview
This project explores student examination data to identify patterns in academic performance and understand how different factors are associated with examination scores.

## 2. Project Objectives
- Compare average scores across Mathematics, Reading and Writing.
- Examine the association between test preparation and academic performance.
- Analyse the relationship between Reading and Writing scores.
- Explore the association between parental education and student performance.

## 3. Dataset
The dataset contains 1,000 student records and 8 variables.

Source: [Students Performance in Exams – Kaggle](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)
